## `$ whoami`

I'm **Sahil Kaushik** — a **Web3 security researcher, smart contract auditor, Web3 developer, and full-stack engineer**. I work across offensive security and software engineering: reviewing protocol logic, tracing state and asset flows, questioning design assumptions, and building blockchain-connected applications and backend systems.

My research approach is to understand the system first, map its trust boundaries, test its assumptions, and validate potential issues against real execution paths. I care about both finding vulnerabilities and building software that is easier to reason about, test, and maintain.
